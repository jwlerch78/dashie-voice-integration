# home-assistant/brands PR staging

**Do not submit until the repos are public** (the PR would leak the name early —
and brands CI links back to the repo).

This directory stages the exact contents for a PR to
[home-assistant/brands](https://github.com/home-assistant/brands), which makes
HA render the Chickadee icon in Devices & Services, the integration picker, and
HACS. The images are generated by [`make_icons.py`](make_icons.py) (same source
as the add-on's icon/logo — keep them in step).

## PR contents

Copy `custom_integrations/chickadee/` into the brands repo at the same path:

```
custom_integrations/chickadee/icon.png       256×256
custom_integrations/chickadee/icon@2x.png    512×512
custom_integrations/chickadee/logo.png       512 wide, landscape
custom_integrations/chickadee/logo@2x.png    1024 wide, landscape
```

## PR steps (launch day)

1. Fork `home-assistant/brands`, branch `add-chickadee`.
2. Copy the directory above; run their linter if the repo currently has one
   (CI validates size/format on the PR anyway).
3. PR title: `Add chickadee (custom integration)`. Body: one line — custom
   integration at https://github.com/jwlerch78/chickadee, domain `chickadee`.
4. Check the current brands CONTRIBUTING.md for rule drift (image size rules
   have changed before) and adjust if CI complains.
